this is a shoping cart programme . it allows user to enter the name of product ,price and the quantity to buy

  fgets()= it reads the item name given by the user

sizeof()= it determines the size of array (item)
strlen()= it calculates the length of the item

format speccifiers used :
 %d= integer values
 %f= floating point values
 %c = display single character
 %s= displays the a string
 %.2f= displays a floating point with two digits after the decimal point
